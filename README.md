# MD Ashik — Full‑stack Developer

This repository contains a static, responsive, and accessible portfolio template for MD Ashik. It ships with a lightweight HTML/CSS/JS build that demonstrates:

- Luxurious black, white, and royal blue color palette
- Glassmorphism, smooth animations, rounded cards, elegant shadows
- Hero, About, Skills, Projects, Experience, Certificates, Services, Gallery, Testimonials, Contact
- Animated skill bars, counters, sticky navbar, dark/light toggle, smooth scrolling
- Recruiter-friendly layout and SEO meta tags

Open index.html in a browser to preview. Replace placeholder content (projects, social links, contact info, CV) with your real data.
